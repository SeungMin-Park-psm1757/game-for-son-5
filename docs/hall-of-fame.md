# Hall of Fame Structure

## Saved Per Match
- `mode`
- `totalScore`
- `arrowScores`
- `xCount`
- `averageStability`
- `averageReleaseQuality`
- `matchDurationMs`
- `windSummary`
- `timestamp`
- `calibrationVersion`
- `resultBand`

## Sort Rules
- Score board: total desc, X desc, newest first
- X board: X desc, total desc, newest first
- Recent list: newest first

## Reset UX
- Tiny corner reset button
- 2 second hold
- Confirmation modal
- `records only`, `calibration only`, `full reset`
